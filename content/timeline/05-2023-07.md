2023 年 7 月初，iDeal 工作室再次遇到一批已开发部署的 Web 应用无法正常访问，排查下来主因仍是 SSL 证书到期。同类故障反复出现，说明靠人记着去续期并不可靠，工作室因此决定开发一款能自动配置 SSL 证书的 HTTPS 代理工具。在**熊老师**带领下，**彭泽辰**与**张亿贺**先做了可行性分析，并用 Go 语言写出了简单原型。

原型跑通之后，讨论的焦点从"修一个故障"转向"要不要立项一个 Web 服务器的开源项目"。**熊老师**认为，工作室过去主要做企业应用软件与互联网应用开发，但从激发大家的学习兴趣、综合利用所学计算机专业基础知识、培养人才的角度，有必要开立一个偏底层的开源项目；而如果要做 Web 服务器软件，建议尽量采用开发效率更高的 Go 语言。

他同时提出一条硬性要求：这个 Web 服务器首先要能被工作室大量的企业项目真正用起来，而不是停留在演示阶段。项目由他亲自命名为 Fast-Https——fast 意指希望这个服务器足够快，https 意指希望它天生支持 HTTPS 协议及 SSL 认证。至此，Fast-Https 正式立项。
