# 基本配置

本页介绍 Fast-Https 控制台的基础设置，帮助你完成首次启动后的必要配置。

## 1 打开管理控制台

启动 Fast-Https 后，在 Windows 任务栏右下角的**系统托盘**找到图标，双击即可打开本地管理控制台。默认访问地址为：

```
http://localhost:8080/
```

## 2 管理端口设置

在「系统设置 → 监听端口」中可以修改控制台监听的端口。修改后需**重启服务**生效。

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 控制台端口 | 8080 | 浏览器访问管理界面所用 |
| 代理 HTTPS 端口 | 443 | 对外提供加密访问 |
| 代理 HTTP 端口 | 80 | 可选，用于重定向到 HTTPS |

## 3 创建第一个站点

1. 进入「站点管理」，点击 **新建站点**；
2. 填写**域名**（如 `example.local` 或已解析的公网域名）；
3. 选择站点类型：**静态目录**、**反向代理** 或 **单页应用**；
4. 保存后站点出现在列表中，状态为「已停止」时点击启动即可。

## 4 让改动生效

大部分配置保存后立即生效；涉及监听端口、证书重签的操作需要重启服务。状态栏会给出明确的提示。

下一步，你可以阅读 [配置发布本地静态站点](/docs/使用教程/配置发布本地静态站点/) 把第一个网站发布出去。
