# 欢迎来到 Fast-Https

Fast-Https 是一个强大的、可扩展的 Web 代理服务器，用于为您的网站、服务和应用程序提供服务；该产品使用 Go 编写。您可以使用 Fast-Https 进行极其简单的配置，即可发布您的 Web 应用。

## 内置支持 HTTPS

大多数人使用 Web 服务器发布 Web 应用时，为了实现 HTTPS 访问，都需要经过漫长而复杂的证书申请和配置；但 Fast-Https 内置了开箱即用的 HTTPS 支持，能够方便地自动生成自签名证书，只需简单配置后即可通过 HTTPS 协议访问您的站点。Fast-Https 非常适合用作临时测试服务器。

## 第一次使用？

没问题！我们建议每个人，无论经验如何，都先阅读一下我们的入门指南。它将让您对这款新的 Web 服务器有一个全面的了解，这对于您继续学习来说将是非常宝贵的。

如果您只有几分钟时间并且需要立即开始工作，请尝试我们的快速入门之一。

我们建议坚持使用这些官方资源来安装、配置和运行 Fast-Https，而不是运行命令或从随机博客和问答版块复制配置片段。您会发现我们的材料通常更加准确和最新。我们还鼓励您制作自己的配置，以确保您了解服务器的工作原理，以便您能够在以后出现问题时更好地解决问题。

但无论您做什么，请享受使用新的网络服务器的乐趣——Fast-Https 的体验不同于您使用过的任何其他服务器软件！
