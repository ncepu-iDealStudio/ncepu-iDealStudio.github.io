# Linux 安装

在 Linux 服务器上装好 Fast-Https 后，会自带一个默认站点：浏览器访问服务器的 80 端口就能看到欢迎页。下面三种方式任选一种，**不要混用**。

## 先确认两件事

下面的命令都在**服务器的终端**里执行，不是在你自己的电脑上。先登录服务器，再运行：

```bash
# 查看系统发行版名称
cat /etc/os-release
# 查看处理器架构
uname -m
```

- 第一条看系统名称：出现 `Ubuntu` 或 `Debian` 选 `.deb` 方式；出现 `CentOS`、`Rocky`、`AlmaLinux`、`openEuler` 等选 `.rpm` 方式。
- 第二条看处理器架构：`x86_64` 对应下载文件名里的 `amd64`，`aarch64` 对应 `arm64`。大多数云服务器是 `x86_64`。

如果仍然不确定，或者你的系统不在上面，选「解压部署」——它只是一个压缩包，不依赖系统的包管理器，任何发行版都能用。

## 我该选哪个

| 你的系统 | 选这个 | 特点 |
| --- | --- | --- |
| Ubuntu / Debian | Ubuntu 安装与部署 | 用 `apt` 安装 `.deb` 包，自动注册系统服务 |
| CentOS / RHEL 系 | CentOS 7 安装与部署 | 用 `yum` 安装 `.rpm` 包，自动注册系统服务 |
| 其他发行版 / 不想装包 | 解压部署 | 解压 `.tar.gz` 即用，服务需要自己注册 |

`.deb`、`.rpm` 是 Linux 的软件包格式，安装后由系统的包管理器记录、可以统一升级和卸载；`.tar.gz` 是压缩包，解压后直接得到程序文件，不经过包管理器。

## 开始之前

- 需要一个能登录服务器的账号，并且能执行管理员命令：`root` 账号直接执行，其他账号在命令前加 `sudo`。
- 默认站点使用 **80（HTTP）和 443（HTTPS）** 端口。如果服务器在云上，先到云厂商控制台的「安全组 / 防火墙」放行这两个端口，否则装好后从外网打不开。
- 这两个端口不能被其他程序占用（例如已经装了 Nginx）。各教程里都有检查端口的命令。
