A Go study group was formed that year, joined by **Zhang Yihe**, **Peng Bo** and **Liu Haoyu**. Studying changed from reading books alone to reading code together and reviewing each other: whoever wrote questionable concurrency logic had to explain it at the weekly meeting. Most of the team's technical consensus grew out of those arguments.

In April the group released a Go interface code generator — repetitive interface boilerplate is generated by the tool, so developers only deal with business logic. It was the first time a daily annoyance was packaged into something others could use. In the same year **Liu Haoyu** applied for a Go innovation programme, which brought a stable research cycle and funding; the loop of "build a project, ship results, invest again" took shape.
