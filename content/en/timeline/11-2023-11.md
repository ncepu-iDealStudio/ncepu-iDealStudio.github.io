In November 2023 Fast-Https started serving the studio's own development and test environments. Real usage is nothing like a demo: wrong paths, occupied ports, broken certificate chains — small problems surfaced all at once and the team fixed them one by one. Those failures later became part of the product.

Around the same time some students began using it for coursework such as Software Testing and the Software Engineering course project. Classrooms are harsher on usability — nobody wants to read a full manual for an assignment — which pushed improvements to the install flow and the interface hints.
