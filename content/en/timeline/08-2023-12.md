In December 2023 **Zhang Jiayue** from software class 2101 joined Fast-Https and took charge of server testing. The team then ran static analysis, unit tests and performance tests across Windows and Linux: static checks kept the codebase consistent, unit tests locked existing behaviour, and performance tests answered the most direct question — is it fast?

Two capabilities were added in the same period: on Linux the server could run as a service, starting on boot and restarting after an unexpected exit; and security work covering response headers and request limits. The first keeps it resident on a server, the second makes it safe to expose to the internet.
