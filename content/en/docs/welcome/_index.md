# Welcome to Fast-Https

Fast-Https is a powerful and extensible web proxy server for your sites, services and applications, written in Go. A small amount of configuration is enough to publish a web app.

## HTTPS built in

Publishing a site over HTTPS usually means a long certificate application process. Fast-Https ships with out-of-the-box HTTPS support: it can generate a self-signed certificate automatically, so your site is reachable over HTTPS right after a few lines of config. That makes it a good fit for temporary test servers.

## First time here?

Start with the installation guide — it gives you the overall picture before you touch any configuration. If you only have a few minutes, jump straight to the platform you are on.

Please rely on these official pages for installing, configuring and running Fast-Https instead of copying snippets from random blogs or Q&A sites; our material is kept accurate and current. Writing your own configuration is encouraged, since understanding it makes later troubleshooting much easier.
