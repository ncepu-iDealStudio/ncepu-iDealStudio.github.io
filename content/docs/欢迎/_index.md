# 欢迎使用 Fast-Https

Fast-Https 是一款运行在 Windows 上的**可视化 HTTPS 与反向代理管理工具**。它的目标是让「给网站启用 HTTPS、把本地服务暴露到公网、发布静态站点」这类原本需要折腾 Nginx 与证书的操作，变成几次鼠标点击。

## 它能帮你做什么

- **签发与管理证书**：一键生成自签名证书，或对接 CA 申请受信任证书，并自动完成下载与系统安装。
- **反向代理**：把本地 `127.0.0.1:port` 的服务通过域名暴露出去，支持 WebSocket 长连接。
- **静态站点发布**：把本地目录或单页应用（SPA）直接发布到外网访问。
- **访问管控**：配置 IP 黑名单、Web 应用访问限流，保护源站稳定。

## 为什么选择它

- **零命令行**：全部配置在图形界面完成，降低上手门槛。
- **本地常驻**：以系统托盘程序运行，随开机自启、后台静默工作。
- **全程加密**：默认启用 TLS 1.3，浏览器地址栏显示安全锁标。
- **开源透明**：代码托管于 Gitee 与 GitHub，可审计、可自构建。
