# 软件获取与安装

## 1 软件安装包获取

项目地址：

- Gitee：https://gitee.com/ncepu-bj/fast-https
- GitHub：https://github.com/ncepu-iDealStudio/Fast-Https

打开系统软件发行下载地址：https://gitee.com/ncepu-bj/fast-https/releases

先确定你的静态站点要发布到哪个平台：

- **Windows 平台**：下载 `fast-https_Windows_x86_64.zip`；
- **Linux 平台**：下载与服务器架构匹配的版本，普通 x86 架构选择 `fast-https_Linux_x86_64.tar.gz`。

![软件发行下载页](/assets/images/1704682382082-4b26d0ad-6ba9-4775-ac79-e2e70b6ca32e-5de1a2447ee22aef630b5f9228fd5617.png)

![选择对应平台版本](/assets/images/1704682640807-8d2758da-c79e-41b7-b47a-8fe56c64327a-5fa421fca4ca41283ae64498a1c22eea.png)

## 2 Windows 平台安装部署

以 Windows 平台为例，下载 `fast-https_Windows_x86_64.zip` 后，先解压压缩包。

![解压软件包](/assets/images/1690185930111-f0d7820d-a9e0-4d8b-9f01-2bd9be8a1d02-1443bda3f6706304bcecef7424201f53.png)

### 修改默认配置文件

在 `config` 目录下打开 `fast-https.conf` 进行站点配置：

![修改配置文件](/assets/images/1704683398571-10a4ae68-51cf-4437-807b-9a84293ffa85-9b2ccc81c7300c3746fac60966d49bfc.png)

默认配置示例如下：

```json
{
  "log_root": "./logs",
  "pid": "./fast-https.pid",
  "http": {
    "include": "mime.types",
    "server": [
      {
        "listen": 8080,
        "server_name": "localhost",
        "location": [
          { "url": "/", "type": "local", "root": "./httpdoc/root", "index": ["index.html", "index.htm"] }
        ]
      },
      {
        "listen": "443 ssl",
        "server_name": "localhost",
        "ssl_certificate": "config/cert/localhost.pem",
        "ssl_certificate_key": "config/cert/localhost-key.pem",
        "location": [
          { "url": "/", "type": "local", "root": "./httpdoc/root", "index": ["index.html", "index.htm"] }
        ]
      }
    ]
  }
}
```

### 启动服务器

打开 `monitor.exe` 启动管理程序：

![启动 monitor](/assets/images/1690187624215-537d4c99-22d9-4ed4-875c-0ccc9bebd5f1-b7ed20f310cdbbbed3dd2389d9900d1f.png)

之后点击任务栏右下角的托盘图标：

![托盘图标](/assets/images/1690187919200-7c36929a-0074-4498-b9cb-37cd410d2a3f-ef7a9c11395999a1d79224d2d522b832.png)

在浏览器访问 `https://localhost:8080/index.html`，即可看到 Fast-Https 的默认启动页面：

![默认启动页面](/assets/images/1693910151061-6ff72dcb-400b-4923-a2ba-a967979e53e0-3c476025c969fbc810f480e849bea56a.png)

至此，Windows 平台下的软件安装完成。

## 3 Linux 平台安装部署

Fast-Https 可以运行在主流的 Linux 平台上。下面以 CentOS 7.9 为例说明安装过程。

```bash
# 创建软件目录
$ mkdir /soft
$ cd /soft

# 下载对应版本
$ wget https://gitee.com/ncepu-bj/fast-https/releases/download/v1.0/fast-https_Linux_x86_64.tar.gz

# 解压到安装目录
$ tar -xzvf fast-https_Linux_x86_64.tar.gz -C /usr/local/fasthttps
$ cd /usr/local/fasthttps/
$ chmod 755 ./fast-https
```

查看配置文件：

```bash
$ cat ./config/fast-https.json
```

![查看配置文件](/assets/images/1704686360918-887022a9-fed3-4995-8277-5b77150c76a1-0e7053079beb4cdb32b13836818a9c41.png)

服务器启动：

```bash
$ ./fast-https
```

![启动服务](/assets/images/1704686730574-a758d894-eee1-4734-a5bf-ee64f55d8b74-8fb3e360cc4a75aeac418f3f534c1dd0.png)

生产环境建议后台运行：

```bash
$ nohup ./fast-https &
```

测试默认站点：

```bash
$ curl http://localhost:8080
```

![测试结果](/assets/images/1704686923053-34ed9fe3-cc54-4144-b4cf-dd24eb5a8e9e-5250ba51a66479c3da5c80062851a4eb.png)

在浏览器输入 `http://ip:8080/index.html` 即可看到默认启动页面，至此 CentOS 上的安装完成。

## 4 以服务方式启动

Fast-Https 也可以安装为系统服务：

```bash
# 安装服务
$ sudo ./fast-https install

# 设置开机自启
$ systemctl enable fast-https.service

# 启动服务
$ sudo systemctl start fast-https.service

# 卸载服务
$ sudo ./fast-https uninstall
```
