# 从源代码构建

如果你希望自行编译 Fast-Https，或从源码参与开发，请按本页步骤操作。

## 1 准备环境

- **Go** ≥ 1.21（用于编译后端服务）
- **Node.js** ≥ 18（用于构建管理控制台前端）
- **Git**（用于拉取源码）

## 2 拉取源码

```bash
git clone https://gitee.com/ncepu-bj/fast-https.git
cd fast-https
```

或同时从 GitHub 获取：

```bash
git clone https://github.com/ncepu-iDealStudio/Fast-Https.git
```

## 3 构建

先构建前端资源，再编译后端可执行文件：

```bash
# 构建管理控制台前端
npm install
npm run build

# 编译后端（Windows）
go build -o Fast-Https.exe ./cmd/server
```

## 4 运行

```bash
# 直接运行
./Fast-Https.exe

# 或安装为系统服务后随开机启动
Fast-Https.exe service install
```

启动后访问 `http://localhost:8080/` 即可进入管理控制台。
