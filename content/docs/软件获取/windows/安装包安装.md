# 安装包安装

从发行页下载 Windows 安装包（`.exe`），双击运行，按向导提示完成安装即可。相比压缩包方式，安装包会把程序写入指定目录，并自动创建快捷方式，卸载时走系统的"应用和功能"。

## 1 下载安装包

在发行页找到 Windows 平台的安装包并下载。

<!-- 截图：发行页中的安装包条目 → /assets/images/docs/install/windows/2.1.png -->

## 2 运行安装向导

双击下载好的安装包，启动安装程序。

<!-- 截图：安装向导首页 → /assets/images/docs/install/windows/2.2.png -->

## 3 选择安装目录

按需修改安装路径，或保持默认目录。

<!-- 截图：选择安装目录 → /assets/images/docs/install/windows/2.3.png -->

## 4 完成安装

等待安装完成后，勾选"立即运行"（如提供）并结束向导。

<!-- 截图：安装完成页 → /assets/images/docs/install/windows/2.4.png -->

## 5 启动与验证

安装完成后，从开始菜单或桌面快捷方式启动 Fast-Https，任务栏托盘会出现程序图标。

<!-- 截图：托盘图标 → /assets/images/docs/install/windows/2.5.png -->

在浏览器访问 `https://localhost:8080/index.html`，看到默认启动页面即安装成功。
