# 压缩包安装

从发行页 [gitee.com/ncepu-bj/fast-https/releases](https://gitee.com/ncepu-bj/fast-https/releases) 下载 `fast-https_Windows_x86_64.zip`，

![发行版下载页](/assets/images/docs/install/windows/1.1.png)

解压到任意目录即可使用，无需安装程序，删除目录即完成卸载。


## 1 解压压缩包

![解压软件包](/assets/images/docs/install/windows/1.2.png)

## 2 修改默认配置文件

在 `config` 目录下打开 `fast-https.json` 进行站点配置：

![修改配置文件](/assets/images/docs/install/windows/1.3.png)

默认配置示例如下：

```json
{
  "http": {
    "server": [
      {
        "listen": 80,
        "server_name": "localhost",

        "location": [
          {
            "url": "/",
            "type": "local",
            "root": "./httpdoc/root",
            "index": ["index.html", "index.htm"]
          }
        ]
      },
      {
        "listen": "443 ssl h2",
        "server_name": "localhost",
        "ssl_certificate": "./config/cert/localhost.pem",
        "ssl_certificate_key": "./config/cert/localhost-key.pem",
        "location": [
          { "url": "/", "type": "local", "root": "./httpdoc/root", "index": ["index.html", "index.htm"] }
        ]
      }
    ],
    "include": ["./config/conf.d"]
  }
}
```

## 3 启动服务器

打开 `monitor.exe` 启动管理程序：

![启动 monitor](/assets/images/docs/install/windows/1.4.png)

之后点击任务栏右下角的托盘图标：

![托盘图标](/assets/images/docs/install/windows/1.5.png)

## 4 验证安装

在浏览器访问 `https://localhost`，即可看到 Fast-Https 的默认启动页面：

![默认启动页面](/assets/images/docs/install/windows/1.6.png)

至此，Windows 平台下的压缩包安装完成。
