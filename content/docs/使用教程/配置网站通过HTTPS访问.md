# 配置网站通过 HTTPS 访问

从 HTTP 到 HTTPS 只需要三步：启动服务、下载证书、安装信任。本页把安全配置的完整链路讲清楚。

## 1 什么是 HTTP 和 HTTPS？它们有何不同？

HTTP 是万维网上传输和共享信息的基础网络技术，但它并不安全——未经授权的人员很容易进行中间人攻击并窃取数据。HTTPS 是 HTTP 的安全版本，在 Web 服务器与浏览器之间对传输数据进行加密。

| 细节 | HTTP 协议 | HTTPS |
| --- | --- | --- |
| 网址 | 前缀 `http://` | 前缀 `https://` |
| 端口 | 80 | 443 |
| 安全 | 存在已知安全问题 | 消除信息交换威胁 |

采用 HTTPS 还能带来搜索引擎优化、合规（如 GDPR）以及防止内容劫持等额外收益，是现代站点的基本要求。

## 2 配置 SSL 自签名证书

### 2.1 第一步　启动 Fast-Https 服务

点击任务栏右下角托盘图标，启动本地 Web 管理服务。

### 2.2 证书下载

在浏览器访问本地管理地址，于控制台下载根证书 `root.crt`。

```
http://localhost:8080/
```

### 2.3 证书安装（Windows 平台）

在下载目录找到 **root.crt**，选择「当前用户」并完成导入，即可让系统信任该自签名证书。完成后地址栏将出现锁形图标。
