# 配置发布本地静态站点

本页演示如何把本地构建好的静态站点，通过 Fast-Https 发布到外网访问，覆盖 Windows 与 Linux 两个平台。

## 1 软件获取

先在发行下载页获取对应平台的安装包：

- Windows：`fast-https_Windows_x86_64.zip`
- Linux：`fast-https_Linux_x86_64.tar.gz`

![软件发行下载页](/assets/images/1704682382082-4b26d0ad-6ba9-4775-ac79-e2e70b6ca32e-5de1a2447ee22aef630b5f9228fd5617.png)

![选择平台版本](/assets/images/1704682640807-8d2758da-c79e-41b7-b47a-8fe56c64327a-5fa421fca4ca41283ae64498a1c22eea.png)

## 2 安装部署 - Windows 平台

### 软件包解压

下载完成后，先解压压缩包：

![解压软件包](/assets/images/1690185930111-f0d7820d-a9e0-4d8b-9f01-2bd9be8a1d02-1443bda3f6706304bcecef7424201f53.png)

### 静态站点代码上传到服务器

把你的静态站点文件放入发布目录（默认 `./httpdoc/root`），确保其中包含 `index.html`：

![上传静态站点代码](/assets/images/1690186526951-857be252-b9eb-4d15-9f8a-bad556e68ead-9208bdab443f75e954f879c9ca4be3da.png)

### 修改配置文件

在 `config` 目录下打开 `fast-https.conf`，将 `root` 指向你的静态目录：

![修改配置文件](/assets/images/1704683398571-10a4ae68-51cf-4437-807b-9a84293ffa85-9b2ccc81c7300c3746fac60966d49bfc.png)

```json
{
  "listen": 8080,
  "server_name": "localhost",
  "location": [
    { "url": "/", "type": "local", "root": "./httpdoc/root", "index": ["index.html", "index.htm"] }
  ]
}
```

### 启动服务器管理程序

打开 `monitor.exe`，点击托盘图标启动服务：

![启动管理程序](/assets/images/1690187624215-537d4c99-22d9-4ed4-875c-0ccc9bebd5f1-b7ed20f310cdbbbed3dd2389d9900d1f.png)

![托盘图标](/assets/images/1690187919200-7c36929a-0074-4498-b9cb-37cd410d2a3f-ef7a9c11395999a1d79224d2d522b832.png)

访问 `http://localhost:8080/index.html` 即可看到站点页面：

![启动页面](/assets/images/1690187273965-e0cda98e-7953-437b-a770-eee6032d2a29-62cf643e0d2a11e9bd519b2b99d47c81.png)

## 3 Linux 平台安装部署

### 3.1 静态站点代码上传服务器

将静态站点文件上传到服务器发布目录（默认 `./httpdoc/root`）：

![上传静态站点代码](/assets/images/1690186526951-857be252-b9eb-4d15-9f8a-bad556e68ead-9208bdab443f75e954f879c9ca4be3da.png)

### 3.2 修改配置文件

编辑 `config/fast-https.json`，把 `server_name` 改为服务器 IP，并确认 `root` 指向静态目录。

```bash
$ cat ./config/fast-https.json
```

### 3.3 启动并测试

```bash
$ ./fast-https
# 或后台运行
$ nohup ./fast-https &
```

![启动服务](/assets/images/1704686730574-a758d894-eee1-4734-a5bf-ee64f55d8b74-8fb3e360cc4a75aeac418f3f534c1dd0.png)
