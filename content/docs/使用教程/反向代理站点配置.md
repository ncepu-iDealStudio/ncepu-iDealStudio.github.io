# 反向代理站点配置

反向代理位于客户端与源站之间：客户端访问你的域名，Fast-Https 把请求转发到本地服务，并把响应返回给客户端，源站地址对外不可见。

![反向代理示意](/assets/images/1704702652348-6f4ec6a3-3040-4491-b3ca-e34ba8ad6796-2e11c81d7a8a27282796e59926992f8e.png)

## Windows 平台进行反向代理配置

### 1 启动被代理服务

先在本地启动你要对外提供的服务（例如 `http://127.0.0.1:3000`），确认它在本机可以正常访问。

### 2 编辑配置文件

在 Fast-Https 的 `config` 目录中编辑配置文件，把 `location` 的 `type` 设为 `proxy`，`root` 指向上游地址：

![编辑配置文件](/assets/images/1704682921110-392b4a01-5a2c-44ec-af0d-65364afd4d05-a8eeda838197a4e504e95d790f2dc788.png)

```json
{
  "listen": 8080,
  "server_name": "localhost",
  "location": [
    { "url": "/", "type": "proxy", "root": "http://127.0.0.1:3000" }
  ]
}
```

保存后重启 Fast-Https，访问域名即可看到本地服务的页面。

## 验证

| 配置项 | 说明 |
| --- | --- |
| 上游地址 | 本地服务的 `http://host:port` |
| 路径前缀 | 可选，仅转发指定路径（如 `/api`） |
| 超时时间 | 上游无响应的断开阈值 |

需要长连接（如聊天、推送）的场景，请阅读 [反向代理 WebSocket 接口项目](/docs/使用教程/反向代理WebSocket接口项目/)。
