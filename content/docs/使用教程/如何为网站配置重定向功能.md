# 如何为网站配置重定向功能

重定向用于把访问请求从一个地址自动转到另一个地址，常见场景包括 HTTP 跳转到 HTTPS、旧域名跳转到新域名等。

## 1 常见重定向类型

| 类型 | 示例 | 用途 |
| --- | --- | --- |
| HTTP → HTTPS | `http://a.com` → `https://a.com` | 强制加密访问 |
| 域名跳转 | `old.com` → `new.com` | 更换域名 |
| 路径跳转 | `/temp` → `/` | 临时页面下线 |

## 2 配置步骤

1. 进入站点「高级设置 → 重定向规则」；
2. 选择重定向类型并填写源地址与目标地址；3. 设置重定向码（301 永久 / 302 临时）；
4. 保存并重启站点生效。

## 3 建议

- 正式上线、长期不变的跳转使用 **301**；
- 活动页、临时维护使用 **302**；
- 开启「HTTP 自动跳转 HTTPS」可让所有明文请求自动升级为加密连接。

与重定向配合，建议同时为站点启用加密，参见 [配置网站通过 HTTPS 访问](/docs/使用教程/配置网站通过HTTPS访问/)。
