# 配置服务器访问 IP 黑名单

IP 黑名单用于屏蔽特定来源的请求，快速拦截恶意爬虫、攻击来源或不需要的访问者。

## 1 添加黑名单

在「安全 → 访问黑名单」中：

1. 点击 **新增规则**；
2. 填写需要封禁的 IP 或网段，例如：

```
192.168.1.100
10.0.0.0/24
```

3. 选择生效范围（全局或指定站点）；
4. 保存即时生效。

## 2 匹配规则

| 形式 | 示例 | 含义 |
| --- | --- | --- |
| 单 IP | `1.2.3.4` | 封禁该地址 |
| CIDR | `1.2.3.0/24` | 封禁整个网段 |
| 通配 | `*.example.com` | 按主机名匹配（可选） |

## 3 注意

- 黑名单优先于白名单之外的一般放行策略；
- 误封自己时，可在本机 `127.0.0.1` 始终放行的保障下登录控制台移除规则。

配合限流使用效果更好，参见 [配置 Web 应用访问限流](/docs/使用教程/配置Web应用访问限流/)。
