# 三方向 · 了解我们（汇报 PPT）

## 共同 spec
- 项目：Fast-Https 团队「了解我们」页，改成汇报 PPT 风格
- 尺寸：1920×1080，每方向 2 页代表页（封面 + 时间线）
- 受众距离：10m 投屏，低密度、大字
- 核心信息：2019→2024 的 Go 产品线成长、15 个关键节点、1.0.0、openEuler
- 内容：真实团队大事记，不编造
- 可读性：正文 ≥24px，标签 ≥16px（三版统一）

---

## 方向 A｜技术蓝图
- 文件：`design-demos/timeline/dir-1.html`
- 逻辑与来源：最佳设计师·克制派（工程图纸传统 + 瑞士网格思维），不用现成模板
- 借的是什么：48px 细网格、等宽标签、水平「发布轨道」、低饱和蓝 + 少量深青
- 主角素材：程序化网格 + 超大年份 + 水平轴，无照片
- 骨架：封面＝标题 + 右侧 1.0.0 数据卡 + 底部年份轴；内页＝一条贯穿全宽的水平发布轨道，5 个节点卡片等距落下
- 胆量花在哪：整页铺满技术网格，把时间线做成一条产品发布轨道
- form 来自内容的哪里：Fast-Https 是版本驱动的服务器产品，时间轴天然就是「发布轨道」

## 方向 B｜年度报告
- 文件：`design-demos/timeline/dir-2.html`
- 逻辑与来源：现实参照·编辑设计（大学/机构年度报告、年鉴排印），靠字体层级而非图形
- 借的是什么：超大衬线年份、两栏「年份—事件」账簿、细分割线、红黑双色
- 主角素材：字体本身（衬线大数字）+ 密排文本，无照片
- 骨架：封面＝「2019—2024」超大衬线数字 + 标题 + 右侧数据栏；内页＝7 行两栏年表
- 胆量花在哪：封面让「2019—2024」占满上半页，标题退居其次
- form 来自内容的哪里：这是一份学生工作室的「年鉴」，用年鉴排印讲成长史

## 方向 C｜发布控制台
- 文件：`design-demos/timeline/dir-3.html`
- 逻辑与来源：秒数轮盘·深底单点缀的工程控制台语言（本次唯一「用力」的一版）
- 借的是什么：近黑底、单一荧光青、等宽字体、纵向 release feed、点阵背景
- 主角素材：程序化点阵 + 荧光节点 + 纵向 feed，无照片
- 骨架：封面＝超大「1.0.0」+ 右侧 release feed；内页＝左侧纵向时间流 + 右侧数据面板
- 胆量花在哪：把大事记做成开源项目的 release log / commit history
- form 来自内容的哪里：Fast-Https 是开源项目，成长史就是一条版本发布日志
