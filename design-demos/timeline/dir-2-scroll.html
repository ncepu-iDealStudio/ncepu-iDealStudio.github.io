2019—至今

一条 Go 语言产品线的成长

从学习小组到正式立项，从 1.0.0 到 openEuler 社区。向下滚动，按时间顺序看这条产品线如何一步步长出来。

向下滚动 · 开始
2019
开始

开启 Go 语言产品线

工作室正式开启 Go 语言技术学习和产品线，软件 1901 班李瑞阳成为第一批 Go 语言学习成员。

2020
学习

学习小组与首个开源项目

成立 Go 语言学习小组，张亿贺、彭博、刘浩宇加入；4 月发布「Go 语言接口代码生成器」，并由刘浩宇负责申报 Go 语言大创项目。

2022
探索

基于 IPFS 的去中心化 Blog

张亿贺负责开发一款使用 Go 语言、基于 IPFS 的开源 Blog 发布系统，可构建无服务器、去中心化的发布与管理方案。

2023.06
组队

彭泽辰加入团队

凭已商业化的静逸教育支援填报辅助系统与一个开源的 C 语言 Web 请求处理框架获得认可，成为 Fast-Https 的主要创始人。

2023.07
立项

Fast-Https 正式立项

为解决 SSL 证书到期导致的应用访问问题，团队用 Go 做出原型。熊老师将项目命名为 Fast-Https——足够快，且天生支持 HTTPS 与 SSL 认证。

2023.09
发布

Windows 版本与托盘程序

确定桌面应用需求，采用 goreleaser 多平台打包，改进日志与后台运行控制；9 月 24 日 Windows 版本正式发布。

2023.10
模块化

安全模块与模块化封装

新增 safe、cache、auth 等功能模块；借鉴 caddy、gin-gonic 等项目的设计，规范各业务模块的执行流程。

2023.12
测试

全面测试与 Linux 服务化

张家悦加入负责测试；在 Windows 与 Linux 平台开展静态、单元与性能测试；新增 Linux 服务化启动与 Web 安全相关设计。

2024.01
里程碑

Fast-Https 1.0.0 正式发布

Windows 与 Linux 双平台能力成型，功能模块稳定，产品迎来首个正式版本。

2024.05
社区

荣誉与 openEuler 社区

大创项目定级国家级优秀；挑战杯首都大学生创业计划竞赛获北京市三等奖；通过华为审核，正式入驻 openEuler 社区。

至今
持续中

持续参赛与迭代

团队继续参加中国国际大学生创新大赛、全国大学生信息安全竞赛等赛事，并在真实项目中持续打磨产品。
